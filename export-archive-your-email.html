How to Export & Archive Your Email (Without Losing Anything)

The Kernel Patch — plain-language tech notes

If your inbox has quietly grown to 10,000, 20,000, or more emails, it's not just clutter — it slows down search, backups, and sometimes the app itself. Archiving doesn't mean deleting. It means moving old email into a safe, separate file you can pull from later if you ever need to.

Step 1: Create the archive file

In classic Outlook for Windows:

  1. Go to File → Open & Export → Import/Export.
  2. Choose Export to a file, then Next.
  3. Choose Outlook Data File (.pst), then Next.
  4. Select the folder (or your whole mailbox) you want to archive, then Next.
  5. Pick where to save the file — a "Backups" folder on your computer or an external drive works well — and click Finish.
If you're on New Outlook: it now has its own export option under Settings → Files → Export, but it only covers mail — calendar and contacts still aren't included, and it can't import a .pst back in. For a full mailbox export/import (or to get calendar and contacts into the archive too), switch to classic Outlook: look for a "New Outlook" toggle in the top corner of the app, switch it off to run the full Import/Export from there, then switch back.

Step 2: Set your comfort line

A common approach: archive anything older than 1–2 years, and keep anything recent or anything you're actively referencing in your live inbox.

Step 3: Know how to get an email back

Your archive file isn't gone — it just isn't loaded into your everyday view. To pull something out of it later:

  1. Go to File → Open & Export → Open Outlook Data File.
  2. Browse to the .pst file you saved and select it.
  3. It'll appear as its own folder in your left-hand sidebar — search or browse it like any other folder.

You can close it again when you're done; the file stays safely wherever you saved it.
