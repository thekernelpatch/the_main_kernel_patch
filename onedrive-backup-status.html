Is My File Actually Backed Up? Reading Your OneDrive Icons

The Kernel Patch — plain-language tech notes

If your Windows computer is set up with OneDrive, your personal folders (Documents, Desktop, Pictures, and similar) can sync to the cloud automatically. But "it's set up" and "this specific file is actually backed up right now" are two different questions — and the small icon next to each file tells you which one you're looking at.

The prerequisite

Backup only works if the folder itself has a small cloud icon on it in File Explorer, and you have an active Microsoft 365 subscription with enough storage. No active subscription or no cloud icon on the folder means nothing inside is being backed up, no matter what the individual file icons say.

What the icons on individual files mean

IconWhat it means
Green circle with checkmarkDownloaded to this computer and backed up to the cloud.
Cloud outline (no checkmark)It's in the cloud, but not currently downloaded onto this computer. It'll download automatically when you open it.

There's a third variant worth knowing: a solid green circle means the file is set to "Always keep on this device" — same backed-up-and-downloaded status as the outlined checkmark, but Windows won't automatically free up its space if your drive gets full.

How to actually confirm a file is backed up

  1. Right-click the file in File Explorer.
  2. Choose More options.
  3. Choose View online.

If it opens in your browser at onedrive.live.com, that's your confirmation — it's genuinely in the cloud, not just marked that way on your computer.

Bonus: because it's in the cloud, you can get to that same file from any other computer or phone by signing into onedrive.live.com — handy if you're away from your usual machine.
